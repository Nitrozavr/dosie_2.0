# Досье 2.0 

Веб-приложение для работы с информацией о спортивных объектах Москвы: карта, карточки объектов, документы, отчёты, статистика и обратная связь.

Проект реализован на **ASP.NET Web Forms** (C#) и работает **полностью локально**, без подключения к внешним базам данных. Все данные хранятся в памяти приложения в файле `LocalData.cs`.

## ✨ Возможности

- **Карта объектов** — интерактивная карта Москвы с маркерами спортивных объектов.
- **Фильтры** — по округу, району, руководителю, типу, направлению.
- **Поиск** — по названию, адресу, категории, руководителю.
- **Карточка объекта** — фотогалерея, основная информация, сведения о зданиях, земельном участке, инженерных системах, документах, спортивных зонах.
- **Документы** — перечень документов и мероприятий, обязательных к наличию на объектах.
- **Отчёты** — сводные таблицы по объектам с экспортом в Excel.
- **Инфографика** — графики по обращениям граждан (статистика, ТОП объектов, динамика).
- **Бюджет** — таблицы исполнения бюджета по КФО, КОСГУ, направлениям.
- **Обратная связь** — форма создания заявки с загрузкой файлов.
- **Управление пользователями** — роли и права доступа.

---

## 🛠 Стек технологий

- **Backend:** ASP.NET Web Forms (.NET Framework 4.7.2), C#
- **Frontend:** HTML5, CSS3, JavaScript (jQuery), Chart.js, Яндекс.Карты API 2.1
- **Стили:** собственные CSS-файлы, без фреймворков
- **Хранение данных:** `LocalData.cs` — статические `List<T>` в памяти приложения
- **Работа с файлами:** только локальные (без БД и SMTP)
